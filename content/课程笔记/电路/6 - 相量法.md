# 相量法

## 正弦量

$$u(t) = U_m\cos(\omega t + \varphi)$$

| 参数 | 含义 |
|:---:|:---|
| $U_m$ | 幅值（最大值） |
| $\omega$ | 角频率，$\omega = 2\pi f$ |
| $\varphi$ | 初相位 |

有效值：$U = \dfrac{U_m}{\sqrt{2}}$

两个同频率正弦量的相位差等于初相之差：$\varphi_{12} = \varphi_1 - \varphi_2$

## 相量表示

正弦量与相量的对应关系：
$$u(t) = U_m\cos(\omega t + \varphi) \quad \longleftrightarrow \quad \dot{U} = U e^{j\varphi} = U\angle\varphi$$

正弦量的微分与积分仍为同频率正弦量，对应相量域中的代数运算：

$$\frac{du}{dt} \longleftrightarrow j\omega\dot{U} \qquad \int u\,dt \longleftrightarrow \frac{\dot{U}}{j\omega}$$

## 相量图

将各相量画在复平面上，模长为幅值，角度为初相，直观表示各正弦量的相位关系。

- 相量加减：平行四边形法则或首尾相接
- KVL：回路中各电压相量首尾相连构成闭合多边形
- KCL：节点处各电流相量首尾相连构成闭合多边形

> [!tip] 绘制技巧
> 以参考相量（通常取并联元件的电压或串联电路的电流）为实轴，沿相位关系逐一画出其余相量。

## 阻抗与导纳

### 阻抗

元件在相量域中电压与电流的比值：
$$Z = \frac{\dot{U}}{\dot{I}}$$

|   元件   |                     阻抗                      |
| :----: | :-----------------------------------------: |
| 电阻 $R$ |                  $Z_R = R$                  |
| 电感 $L$ |      $Z_L = j\omega L$ (电感的电压超前电流九十度)       |
| 电容 $C$ | $Z_C = \dfrac{1}{j\omega C}$ (电容的电压滞后电流九十度) |

一般形式：$Z = R + jX$

- $R$：电阻（实部）
- $X$：电抗（虚部），$X_L = \omega L > 0$，$X_C = -\dfrac{1}{\omega C} < 0$

### 导纳

$$Y = \frac{1}{Z} = G + jB$$

- $G$：电导（实部）
- $B$：电纳（虚部）

## 相量形式的基尔霍夫定律

$$\text{KCL：} \sum \dot{I}_k = 0 \qquad \text{KVL：} \sum \dot{U}_k = 0$$

形式与直流电路完全相同，只是把电压电流换成相量。

## 相量域的电路分析

直流电路中的分析方法全部适用：

| 方法 | 直流形式 | 相量形式 |
|:---:|:---:|:---:|
| 欧姆定律 | $U = IR$ | $\dot{U} = \dot{I}Z$ |
| 串并联 | $R_{eq} = \sum R_k$ | $Z_{eq} = \sum Z_k$（串联） |
| 分压 | $U_k = \dfrac{R_k}{R_{eq}}U_S$ | $\dot{U}_k = \dfrac{Z_k}{Z_{eq}}\dot{U}_S$ |
| 戴维宁 | $U_{oc}$，$R_{eq}$ | $\dot{U}_{oc}$，$Z_{eq}$ |
