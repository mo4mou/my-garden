# 正弦稳态功率

## 瞬时功率

$$p(t) = u(t)\,i(t) = UI\cos\varphi + UI\cos(2\omega t + \varphi)$$

- $\varphi = \varphi_u - \varphi_i$：电压超前电流的相位差
- 第一项为恒定分量，第二项为以 $2\omega$ 振荡的分量

## 有功功率（平均功率）

$$P = UI\cos\varphi \quad (\text{W})$$

- $\cos\varphi$：功率因数
- 纯电阻：$\varphi = 0$，$P = UI$
- 纯电感/电容：$\varphi = \pm 90°$，$P = 0$

> [!note] 有功功率守恒
> $\sum P_{\text{发出}} = \sum P_{\text{吸收}}$

## 无功功率

$$Q = UI\sin\varphi \quad (\text{var})$$

- 电感吸收无功：$Q_L > 0$
- 电容发出无功：$Q_C < 0$
- LC 并联可就地补偿无功

## 视在功率

$$S = UI \quad (\text{VA})$$


三者关系：
$$S = \sqrt{P^2 + Q^2}=I^{2}|Z| \qquad \cos\varphi = \frac{P}{S}$$


## 功率因数的提高

并联电容补偿无功，使 $\cos\varphi$ 提高到目标值 $\cos\varphi'$：

$$C = \frac{P(\tan\varphi - \tan\varphi')}{\omega U^2}$$

推导：并联电容前后 $P$ 不变，无功从 $Q$ 降为 $Q'$：
$$Q' = P\tan\varphi' \qquad Q_C = Q - Q' = P(\tan\varphi - \tan\varphi')$$
电容提供的无功 $Q_C = \omega C U^2$，解得 $C$。
$\tan\varphi = \dfrac{Q}{P}$，$I_C = \frac{U}{\frac{1}{\omega C}}$

> [!warning] 注意
> 并联电容不影响负载的有功功率和工作状态，只减小总电流。

## 复功率

$$\tilde{S} = \dot{U}\dot{I}^* =  UI∠\varphi_{u}-\varphi_{i}=P + jQ$$

$\dot{I}^*$ 为电流相量的共轭。复功率的模等于视在功率 $S$，实部为有功功率 $P$，虚部为无功功率 $Q$。


## 最大功率传输

正弦稳态下，当负载阻抗 $Z_L$ 与戴维宁等效阻抗 $Z_{eq}$ 共轭匹配时有功功率最大：

$$Z_L = Z_{eq}^* \quad \Longleftrightarrow \quad R_L = R_{eq},\; X_L = -X_{eq}$$
$$\Rightarrow P_{max} = \frac{U_{oc}^2}{4R_{eq}}$$
