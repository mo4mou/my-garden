# 磁场分布

各种典型电流配置的磁感应强度分布。求解方法：毕奥-萨伐尔定律（积分）或安培环路定理（环路）。

- ! 磁场分布具有反对称性，目前基本只设计切向方向的$\vec{B}$

## 基本电流配置

| 系统              |                                  磁感应强度                                  |   方法    | 说明                  |
| :-------------- | :---------------------------------------------------------------------: | :-----: | :------------------ |
| **无限长直导线**      |               $\displaystyle B = \frac{\mu_0 I}{2\pi r}$                | 安培环路/BS | $r$ 为到导线的垂直距离       |
| **有限长直导线**      | $\displaystyle B = \frac{\mu_0 I}{4\pi r}(\cos\theta_1 - \cos\theta_2)$ |  BS定律   | $\theta$ 为两端与场点连线夹角 |
| **环形电流轴线**      |       $\displaystyle B = \frac{\mu_0 I R^2}{2(R^2 + x^2)^{3/2}}$        |  BS定律   | $x$ 为场点到圆心距离        |
| **长直螺线管内部**     |                             $B = \mu_0 n I$                             |  安培环路   | $n$ = 单位长度匝数        |
| **长直螺线管外部**     |                                    0                                    |  安培环路   | 无                   |
| **无限宽、长电流平板**   |                  $\displaystyle B = \frac{\mu_0}{2}j$                   |  安培环路   | $j$ = 单位宽度电流        |
| **有限宽、无限长电流平板** |             $B=\frac{\mu_{0}I}{\pi a} \arctan \frac{a}{2z}$             | 细导线的叠加  | a为宽度，z为离轴线的距离       |

> 核心方法：**对称性高 → 安培环路定理**（类比电场高斯定理）；**对称性低 → 毕奥-萨伐尔定律积分**（类比电场叠加法）。

## 求解思路

1. 判断电流分布的对称性（柱对称、平面对称、轴对称）
2. **对称性好** → 安培环路定理：$\oint \vec{B}\cdot d\vec{l} = \mu_0\sum I_{\text{enc}}$ （环路法）
3. **对称性差** → 毕奥-萨伐尔定律积分：$\displaystyle \vec{B} = \frac{\mu_0}{4\pi}\int\frac{I d\vec{l}\times\hat{r}}{r^2}$ （积分法）
4. 验证：无限远处 $B\to 0$；结果是否符合已知特例
